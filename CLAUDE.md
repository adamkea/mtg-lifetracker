# Claude instructions for this repo

## Commit messages

Always include the following co-author trailer at the end of every commit message body (after a blank line):

```
Co-authored-by: adamkea <admkearney@gmail.com>
```

Example format:

```
Short summary line

Longer description if needed.

Co-authored-by: adamkea <admkearney@gmail.com>
https://claude.ai/code/session_...
```
